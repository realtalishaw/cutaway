| Tab | What's in it |
| --- | --- |
| **Storage** | Where your projects and exports are saved, and what happens when you import a file. |
| **Processing** | The [AI helpers](/ai/set-up-ai), what is allowed to leave your Mac, and how speech is turned into text. |
| **AI generation** | Your ElevenLabs or fal.ai key, for making voices, music, pictures and video with AI. |
| **AI tools** | Let Claude Code or Codex make videos in Cutaway. See [Use Cutaway from Claude or Codex](/ai/make-videos-from-claude-or-codex). |
| **Recording** | Default recording choices, like the countdown. |
| **Accessibility** | Options that make Cutaway easier to see and use. |
| **Shortcuts** | Change any [keyboard shortcut](/help/keyboard-shortcuts). |
| **Presets** | Looks you've saved to reuse. |
| **About** | Which version of Cutaway you have. |

## Where your work is saved

- **Projects**: in the **Cutaway** folder inside your **Movies** folder.
- **Exports**: in the **Cutaway Exports** folder inside your **Movies** folder.

You can change both under **Storage**.

## When you import a file

Under **Storage → Imported media**:

- **Copy into the project** (recommended): your project keeps working even if you move or delete the original file. Uses more space.
- **Leave it where it is**: saves space, but the project needs the original file to stay put.
