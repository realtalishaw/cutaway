---
title: "Keyboard shortcuts"
description: "Handy keys to work faster. You never need these, but they save time."
---

<Tip>
  Press **Command + K** to open the command menu. Type what you want to do, like "export", and press **Return**. You don't need to remember any shortcuts.
</Tip>

In this list, **⌘** is the **Command** key, **⇧** is **Shift**, **⌥** is **Option** and **⌃** is **Control**.

## The ones worth learning

| Key | What it does |
| --- | --- |
| **Space** | Play or pause |
| **⌘ Z** | Undo |
| **⇧ ⌘ Z** | Redo |
| **S** | Split at the playhead |
| **T** | Add text at the playhead |
| **Backspace** | Remove the selected thing |

## Recording

| Key | What it does |
| --- | --- |
| **⌘ N** | New recording |
| **⌃ ⌥ ⌘ R** | Start or stop recording, from any app |
| **⌃ ⌥ F** | Flag this moment while recording |

## Moving around

| Key | What it does |
| --- | --- |
| **←** / **→** | Back or forward one frame |
| **⇧ ←** / **⇧ →** | Back or forward one second |
| **[** / **]** | Go to the previous or next flag |
| **⌥ [** / **⌥ ]** | Look at the previous or next saved version |

## Editing

| Key | What it does |
| --- | --- |
| **I** | Mark the start of a part |
| **O** | Mark the end of a part |
| **X** | Cut the marked part |
| **L** | Keep the marked part (the AI won't change it) |
| **⌘ B** | Split the selected block, or the clip, at the playhead |
| **⌘ L** | Lock the selection, so the AI won't change it |
| **⌘ D** | Duplicate the selected blocks |
| **⌘ C** / **⌘ V** | Copy the selected blocks, then paste them at the playhead |
| **⌥ ←** / **⌥ →** | Move the selected blocks one frame earlier or later |
| **⌥ ⇧ ←** / **⌥ ⇧ →** | Move the selected blocks one second earlier or later |
| **⌃ L** | Camera only, from the playhead |
| **⌃ S** | Screen only, from the playhead |
| **⌃ B** | Screen with camera bubble, from the playhead |

## Keys you can't change

These always work the same way:

| Key | What it does |
| --- | --- |
| **Esc** | Deselect, or stop picking something |
| **⌦** | Remove the selected thing (same as **Backspace**) |

## Change a shortcut

You can change any other shortcut in **Settings → Shortcuts**. Click a shortcut, then press the new keys. If those keys are already used, Cutaway tells you which command has them.
